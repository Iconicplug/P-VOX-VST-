# P-Vox (ICONICO)
Plugin VST3 de dinámica vocal inspirado en el R-Vox. Gate / Comp / Gain.

1. Sube todo el contenido de esta carpeta a un repositorio de GitHub (rama main).
2. Pestaña **Actions** → "Build P-Vox VST3" → al terminar, descarga el artefacto `P-Vox-VST3-Windows`.
3. Copia la carpeta `P-Vox.vst3` a `C:\Program Files\Common Files\VST3\`.
